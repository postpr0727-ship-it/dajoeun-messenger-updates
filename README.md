# 김포다조은병원 Messenger 업데이트

Windows용 병원 내부 메신저의 설치 파일과 자동 업데이트 정보 배포 공간입니다.

## 처음 설치하거나 이전 버전에서 전환할 때

1. 기존 메신저를 작업표시줄 우측 트레이 메뉴에서 종료합니다.
2. [최신 설치 파일](https://github.com/postpr0727-ship-it/dajoeun-messenger-updates/releases/latest)을 받아 설치합니다.
3. 이름과 부서를 설정한 뒤 사용합니다. 기존 데이터가 있으면 유지됩니다.

## 자동 업데이트

0.6.6부터 설치 시 Windows 로그인 자동 실행을 등록합니다. 업데이트가 완료되면 해당 버전의 변경 내용을 별도 창으로 표시하며, 확인할 때까지 유지합니다. 확인하지 않고 종료하면 다음 실행 때 다시 표시합니다.

0.6.5부터 프로그램 시작 시 새 버전이 있으면 다운로드와 설치 후 메신저를 실행합니다. 실행 중 확인한 업데이트는 ‘지금 업데이트’ 버튼으로 적용할 수도 있습니다. 작성 중인 내용이나 진행 중인 전송이 있으면 보호 안내를 먼저 표시합니다.

0.6.0부터 실행 시와 실행 중 6시간마다 새 버전을 확인합니다. 새 버전은 백그라운드에서 다운로드하고 **다음 실행 시** 적용합니다. 수신 대화나 전송 중인 파일 때문에 실행 중인 앱을 강제 종료하지 않습니다.

업데이트는 배포용 전자서명과 SHA-256 검사를 통과한 경우에만 적용됩니다. 설치 전에 프로그램 파일을 백업하고 새 버전의 기본 실행 검사에 실패하면 기존 파일로 복구합니다.

이 저장소는 설치 프로그램과 버전 정보만 배포합니다. 직원 목록, 대화 내용, 받은 파일, PC 식별 키는 업로드하지 않습니다.

현재 시험 배포용입니다. Windows 10/11 64비트용이며 자동 업데이트 기능을 넣기 전 버전은 0.6.0 이상을 한 번 직접 설치해야 합니다.
